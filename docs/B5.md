# B5. Play: the engine behind a Lichess bot account

The engine as it stands, on Lichess, playing whoever challenges it, with every game kept.

## What it is

- `bot/config.yml`: lichess-bot settings. The engine is `target/release/uci` with the default graph, one game at a time, no pondering. It accepts standard games at blitz and rapid (3 to 15 minutes base, up to 20 seconds of increment), casual and rated, from people and bots. It does not challenge anyone. Every game is written to `bot/games/` as PGN.
- `tools/bot.sh`: the one command that runs it. It reads the account's API token without echoing it, offers to turn a fresh account into a bot account, and starts lichess-bot under `caffeinate`.
- `.tools/lichess-bot/` (not tracked): lichess-bot from its master tarball, with its own Python environment. It passes the token to nothing but Lichess; the token is never written to a file.

## Setting up the account

A bot account has to be a new Lichess account with no games, and the upgrade cannot be undone. The token needs only the "Play games with the bot API" scope. `tools/bot.sh` checks both before it upgrades anything.

## Predictions for the first run

1. After the account is a bot account, `tools/bot.sh` reaches "Engine configuration OK" and then holds the event stream open until stopped.
2. In the first 20 games the engine makes no illegal move and loses none on time.
3. Every game finished on Lichess has a record in `bot/games/` (the count of games in the PGN equals the count from Lichess's export for the account).
4. After 30 rated blitz and rapid games the account's Lichess rating is between 1800 and 2400. The Lichess scale is not the CCRL-anchored scale of B4, so this is not a check on that rating.
